# v2 教學工作台

直接開啟 `index.html`，或使用父資料夾的本機預覽服務。原版完整內容保存在同層的 `../v1/`。

## 工作人員製作作品

1. 首頁選「做一本讀物」或「做一支影片」。
2. 「設定對象」填作品名稱、讀者與主角，可套用範例。
3. 「規劃內容」新增頁面／分鏡，或套用骨架，再調整文字、動作與順序。
4. 「交給 AI」選開場、角色或特定頁／鏡，複製並開啟 ChatGPT。確認文字後自行送出。
5. 「檢查與匯出」保留原本排版說明，並提供交付檢查表入口。

首頁「我的作品」可切換不同讀物／影片，也可匯出原有 JSON 腳本備份。清除瀏覽器資料前先匯出；Git push 不會備份瀏覽器內作品。

## 帶領活動

1. 工作人員到「活動與人物卡」，選內建活動或新增一份活動包。
2. 指定人物、可選地方與畫風；需要教提示詞時，勾選保留「看指令」步驟。
3. 按「開始活動」，系統切到易學版，人物與畫風已準備好。
4. 使用者依序選地方、動作、心情，看圖卡摘要，再交給 AI。

自由模式可選常用人物，或按「自己設定人物」沿用九題選擇。選完不自動跳頁，需按下一步確認。

## 圖卡管理與備份

- 由工作人員版的側欄或首頁進入「圖卡管理」。
- 選題目後可搜尋、更換圖片、新增圖卡、排序或隱藏選項。預覽可查看使用者可見的圖卡。
- 每題至少保留一張圖卡。活動包還會再篩選地方；若指定選項已不可用，需先調整活動。
- 按「匯出圖卡與活動」保存圖卡圖片、自訂描述、人物卡、活動包、顯示與排序設定。
- 換電腦後匯入同一份備份；匯入前先檢查內容與取代提示。壞檔不覆寫原設定，作品清單也不受圖卡備份影響。
- 作品腳本和圖卡活動是不同備份，換機時兩種都要匯出。

## AI 交接

「把提示詞帶到 ChatGPT」會先複製指令並嘗試開啟網站；外部服務不保證接受網址內容，必要時自行貼上。回來後按「我看到圖片了」才進入圖像檢查。沒有打開或不知道怎麼貼上，可使用頁面上的協助按鈕。

目前沒有在本站內呼叫付費生成服務，也不會自行送出 ChatGPT 對話。畫風示例是選項說明，不代表 AI 已經完成圖片。

## 文件轉易讀

先帶著改寫指令前往 ChatGPT，文件只在 ChatGPT 附上即可。本站「把檔名加進指令」是選用功能，不讀取或傳送文件內容。完成後核對重要日期、數字與條件。

## 設計與驗證

沿用既有 Neutral 黑白介面、Lucide 圖示、本機字型與教材。工作人員版預設改為 16pt，保留 12／20／32pt；易學版保留 20pt 與四種字級。

語法、備份驗證、完整操作與響應式檢查方式見父資料夾 README。`design-assets-manifest.json` 記錄參考原則與本次生成畫風示例。

本版存檔使用 `rbot_v2_` 前綴，v1 使用原本前綴。v1 的舊腳本 JSON 可在 v2「規劃內容」使用原有匯入功能；瀏覽器中的圖卡不會自動跨版同步。
