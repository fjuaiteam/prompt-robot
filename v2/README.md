# v2 教學工作台

直接開啟 `index.html`，或使用父資料夾的本機預覽服務。原版完整內容保存在同層的 `../v1/`。

## 工作人員製作作品

1. 首頁選「做一本讀物」或「做一支影片」。
2. 「設定對象」填作品名稱、讀者與主角，可套用範例。
3. 「規劃內容」新增頁面／分鏡，或套用骨架，再調整文字、動作與順序。
4. 「交給 AI」先檢查空白與骨架示例。第一段可開新的 ChatGPT 對話；角色與後續頁／鏡請複製後回同一個對話貼上，再自行送出。本站不會自動確認 AI 已收到。
5. 每段可按「我已在同一對話送出這段」手動記錄，再前往下一段；重新整理會保留紀錄。只有複製不會標成送出。
6. 「排版與交付檢查」說明如何在外部工具完成教材，並提供手動素材／交付確認與檢查表。更改設定或腳本後，舊交接與完成確認會重設，需重新核對。

首頁「我的作品」可切換不同讀物／影片，也可匯出原有 JSON 腳本備份。清除瀏覽器資料前先匯出；Git push 不會備份瀏覽器內作品。

首頁會區分腳本草稿、交接中、外部素材已完成、已確認可交付；後兩項都是使用者自行確認，不是系統檢查到外部成品。「頁／鏡」表示腳本數量，不是已生成數量。

## 帶領活動

1. 工作人員到「活動與人物卡」，選內建活動或新增一份活動包。
2. 指定人物、可選地方與畫風；需要教提示詞時，勾選保留「看指令」步驟。
3. 按「開始活動」，系統切到易學版，人物與畫風已準備好。
4. 使用者依序選地方、動作、心情，看圖卡摘要，再交給 AI。

自由模式可選常用人物，或按「自己設定人物」沿用九題選擇。選完不自動跳頁，需按下一步確認。

人物清單提供設定摘要與編輯，內建人物可另存副本；編輯被活動引用的人物會先確認影響範圍。新增／編輯人物不會清空同頁的活動草稿。活動與人物草稿在目前分頁暫存，不保證關閉或重整後恢復，請按儲存完成。

三張內建人物用單人示意圖。其他外觀或相關圖卡描述已改動時，只列文字設定，不用不相符的人像代替；不代表真的生成了作品角色。

## 工程模式（圖卡管理）與備份

- 由工作人員版側欄的固定「工程模式」入口進入。易學版首頁底部也保留入口，需經工作人員確認。
- 左側選題目、中間選圖卡、右側編輯。桌面以三欄呈現；窄畫面分類改成抽屜／下拉選單，編輯器放在圖卡下方。
- 圖片、名稱、AI 描述與顯示設定先暫存，按「儲存變更」才一起保存；離開前會確認未儲存的變更。
- 可新增圖片與圖卡、搜尋、排序、隱藏選項，也可恢復預設。內建的性別／年齡／修正規則文字及「沒有輔具」不開放修改，避免破壞組句。
- 「備份與使用者預覽」區可預覽使用者可見圖卡，或匯出／匯入。備份含內建圖卡的名稱與描述調整；舊備份仍可讀取，較舊 v2 不支援新的文字調整欄位，請勿用它覆蓋新備份。
- 每題至少保留一張圖卡。活動包還會再篩選地方；若指定選項已不可用，需先調整活動。
- 按「匯出圖卡與活動」保存圖卡圖片、自訂描述、人物卡、活動包、顯示與排序設定。
- 換電腦後匯入同一份備份；匯入前先檢查內容與取代提示。壞檔不覆寫原設定，作品清單也不受圖卡備份影響。
- 作品腳本和圖卡活動是不同備份，換機時兩種都要匯出。

工作台與活動頁的「備份與還原」也可操作，不必先進工程模式。作品的「更多 → 下載設定與腳本備份」包含該作品設定、兩類腳本與手動進度，不含外部 AI 圖片／影片／PDF。用「還原作品備份」新增一份作品，不覆蓋原作品；上限 5 MB、每類腳本最多 500 頁／鏡，不匯入個人範本。舊版含設定與兩類腳本的備份仍可還原，未含進度者顯示未確認。

## AI 交接

「把提示詞帶到 ChatGPT」會先複製指令並嘗試開啟網站；外部服務不保證接受網址內容，必要時自行貼上。回來後按「我看到圖片了」才進入圖像檢查。沒有打開或不知道怎麼貼上，可使用頁面上的協助按鈕。

貼上協助改成一次一個動作；可以前後切換，並可選「請工作人員陪我」，保留原選擇不重來。手機只顯示目前階段，選項仍可往下捲動查看。

目前沒有在本站內呼叫付費生成服務，也不會自行送出 ChatGPT 對話。畫風示例是選項說明，不代表 AI 已經完成圖片。

## 文件轉易讀

先帶著改寫指令前往 ChatGPT，文件只在 ChatGPT 附上即可。本站「把檔名加進指令」是選用功能，不讀取或傳送文件內容。完成後核對重要日期、數字與條件。

## 設計與驗證

依使用者核准的三張視覺稿實作：沿用白底 Neutral、Lucide、本機字型與教材，加入低彩度深青綠重點色。首頁突出續作，保留文件改寫與畫圖片捷徑。兩張縮圖僅為類型示意，不是實際生成封面；已有作品不會被示例內容取代。工作人員版預設 16pt，保留 12／20／32pt；易學版保留 20pt 與四種字級。

語法、備份驗證、完整操作與響應式檢查方式見父資料夾 README。先執行 browser-check.js，再執行 `playwright-cli -s=v2check run-code --filename=v2/tests/studio-check.js`，可在隔離資料區驗證新編輯器與視覺。`design-assets-manifest.json` 記錄圖稿來源、類型縮圖及畫風示例。

本版存檔使用 `rbot_v2_` 前綴，v1 使用原本前綴。v1 的舊腳本 JSON 可在 v2「規劃內容」使用原有匯入功能；瀏覽器中的圖卡不會自動跨版同步。

2026-10-19 的新手情境回歸：在背景隔離 session 執行 `playwright-cli -s=v2check run-code --filename=v2/tests/ux-check.js`。此測試會清除該隔離 session 的 v2 資料，請勿對個人瀏覽器執行；外部 AI 與剪貼簿均攔截。涵蓋交錯編輯草稿、人物卡、圖卡完整呈現、求助焦點、手動交接／完成狀態與作品備份還原。
## 雲端圖片交件

工作台與易學版新增「登入／交件」入口。學員使用預發帳密登入，第一次確認姓名、組別與活動代碼，選擇已下載的 AI 圖片，預覽後交件；每場一張，可重交。原圖最多 20 MiB，瀏覽器轉成長邊 2,048 px 以內、1 MB 以內 JPEG，透明背景轉白底。

講師由 `admin.html` 登入管理活動、帳號、交件搜尋與 ZIP／CSV。正式活動先保持關閉，由講師按「開放交件」；已有的本機教材草稿／圖卡不會自動上傳。部署、權限、免費額度與課前演練詳見 [部署說明](../docs/training-deployment.md)。
